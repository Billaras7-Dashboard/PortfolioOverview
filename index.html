📤 Export & Backup

JSON = πλήρες backup, χρησιμοποίησε για restore.
CSV = ανοίγει σε Excel/Sheets απευθείας.
Excel = report με 7 sheets, γραφήματα-ready.

📁 Google Drive — Βήμα βήμα:
1. Πάτα Export Full Backup (JSON)
2. Ανέβασε το .json στον φάκελο Portfolio_Backup στο Drive
3. Ανέβασε και το .html αρχείο εκεί
4. Σε νέα συσκευή: κατέβασε και τα 2, άνοιξε το .html
5. Πάτα Import → διάλεξε το .json → έτοιμο!
→ Repeat: κάνε export μετά από κάθε ενημέρωση τιμών ή νέα αγορά
📥 Import & Restore

Import JSON = αντικαθιστά ΟΛΑ τα δεδομένα.
Import CSV Log = προσθέτει εγγραφές χωρίς να σβήσει τίποτα.
Κάνε πάντα export πριν το import!
